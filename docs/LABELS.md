# 유통명 수집 절차

`zero_soda_label.json` 을 채우는 방법. **손으로 검증해 넣는다.** 자동 수집 금지.

## 왜 필요한가

C002 의 제품명은 **품목제조보고 등록명**이지 유통명이 아니다.
실제로 `나랑드 사이다 제로`로 팔리는 제품이 `나랑드사이다`로 신고돼 있다.
같은 제품이 등록명·유통명 양쪽으로 중복 신고된 경우도 있다.

## 절차

1. 허용된 공식몰에서 제품 상세페이지를 연다.
2. 상세 설명은 대개 `#prdDetail` 안의 **긴 이미지 한 장**이다. 지연 로드라
   스크롤해야 나온다. 이미지 URL을 받아 내려받는다.
3. 이미지에서 두 곳을 읽는다.
   - **상품정보제공 고시** 표의 `제품명` → 유통명
   - **제품 라벨 사진**의 `원재료명` 과 **`품목보고번호`**
4. **품목보고번호로 검증한다.** 이게 핵심이다 — 이름을 추측하지 않고
   C002 레코드에 정확히 붙일 수 있고, OCR 이 맞았는지도 같이 검증된다.

   ```bash
   python - <<'PY'
   import sys; sys.path.insert(0,'.')
   import zero_soda_scan as z
   rows,_ = z.load_raw_full('zero_soda_raw.json')
   by = {}
   for r in rows:
       by.setdefault(z.pick(r, z.FIELD_REPORT_NO).strip(), []).append(z.pick(r, z.FIELD_NAME))
   for no in ["1973028800636", "1996061705334"]:
       print(no, "->", by.get(no, "없음"))
   PY
   ```

   조회 결과가 예상한 제품이 아니면 **넣지 않는다.** 숫자를 잘못 읽은 것이다.
5. `zero_soda_label.json` 의 `labels` 에 보고번호별로 넣는다.
   `유통명`·`출처`(URL)·`확인일` 세 개가 **전부** 있어야 한다.
6. `python zero_soda_scan.py --mode build` 로 반영하고 결과를 확인한다.

## 주의

- 원재료는 **C002 가 혼합제제로 가려 감미료를 알 수 없을 때만** 넣는다(`원재료` 필드).
  이때만 티어를 고시 표시 원재료로 다시 판정하고, 리포트 상세에 출처와 함께 밝힌다.
  C002 로 이미 판정된 제품은 건드리지 않는다 - 정부 신고 데이터가 우선이다.
- **대량 수집하지 말 것.** 롯데마트 제타는 몇 번만 연속 요청해도 `HTTP 202`
  봇 챌린지로 막힌다. 검색 API 가 아니라 상점이다. 필요한 제품만 하나씩 본다.
- 팩 단위 SKU(`245ml 30입`)가 아니라 **제품 단위 이름**을 넣는다.
- 유통명이 붙은 제품은 리포트 상세에 **등록명과 출처 링크가 함께** 표시된다.
  출처 없이 이름만 바꾸면 이 프로젝트의 근거 원칙이 깨진다.

## 남은 작업 — 정보가 더 필요한 제품

`616`개 중 아래가 미해결이다. 우선순위 순.

### 1. 감미료 미표기 2건

C002 신고 원재료가 `식품첨가물혼합제제` 등으로 뭉뚱그려져 **어떤 감미료를 썼는지 알 수 없다.**
현재 `무감미료`(최상위)로 표시되고 경고 표시만 붙어 있어, 실제보다 좋게 보인다.
고시 표시 원재료를 찾아 `zero_soda_label.json` 의 `원재료` 에 넣으면 자동으로 재판정된다.
(코카콜라 제로가 이 경로로 `무감미료` -> `B` 로 바로잡혔다.)

| 제품명 | 업소명 |
|---|---|
| 클리어제로 | 롯데칠성음료(주) |
| 타이탄 제로 | 대경사과원예농협음료가공공장 |

**롯데마트 제타에서 더 못 캐는 이유** — 2026-08-13 실측. 고시표의 `1-6.원재료명` 은
거의 항상 `라벨에표기`/`상세페이지 참조` 다. **갤러리에 라벨 사진이 있는 상품만** 해결된다.

| 상황 | 결과 |
|---|---|
| 갤러리에 라벨 이미지 있음 (500~960px) | 판독 성공 — 스프라이트 3종, 환타 2종, 캐나다드라이, 닥터페퍼 스트로베리 |
| 라벨 이미지 없음 (본품 사진만) | 불가 — 닥터페퍼 제로, 하이트 제로 |
| 라벨 이미지가 500px 뿐 | 품목보고번호 판독 불가 — 코카-콜라 제로 레몬. 800px 이상 변형은 403 |
| 제타에 상품 자체가 없음 | 환타 제로 오렌지·포도향, 갈배사이다 제로, 클리어제로, 타이탄 제로 |

이미지는 지연 로드라 **끝까지 스크롤한 뒤 맨 위로 돌아와야** 갤러리가 다 잡힌다.
`naturalWidth` 로 거르면 라벨을 놓친다.

**마켓컬리가 제타보다 낫다** - 2026-08-13 실측. 상세 이미지가 라벨 전문을 그대로 스캔한
1010px 이상 이미지라 품목보고번호까지 읽힌다. 절차는 아래와 같다.

1. 검색: `https://www.kurly.com/search?sword=<검색어>` → `a[href*="/goods/"]`
2. 상세를 끝까지 스크롤해 지연 로드를 끝낸 뒤 `img[src*=goodsview]` 를 모은다.
   **상세 이미지는 `img-cf.kurly.com/...goodsview/...` 다.** 갤러리의
   `product-image.kurly.com` 만 보면 라벨을 놓친다.
3. 이미지는 `Referer: https://www.kurly.com/` 를 붙이면 직접 받아진다.
   `product-image.kurly.com` 쪽은 403 이고 canvas 도 tainted 라 못 뽑는다.

남은 8건 중 코카콜라 3종(레몬·레몬라임·체리)은 컬리·제타 어디에도 없다.
`www.7-eleven.co.kr` 과 `gs25.gsretail.com`(둘 다 robots 허용)이 미실증으로 남아 있다.

### 3. 영양 데이터가 없는 199건

열량·당류가 공란이라 `실측제로` 판정을 못 한다(제품명의 제로 표기에만 의존).
공공데이터포털 `15100066` 이 대형 브랜드를 잘 안 싣는 탓이라 개별 보강 외에 방법이 없다.
건수가 많아 **전수 해소는 현실적이지 않다.** 검색이 많은 제품부터 선별할 것.

### 4. 유통명이 등록명과 다른 제품 (건수 미상)

`나랑드사이다` -> `나랑드사이다 제로` 같은 사례. 전수 파악할 방법이 없다.
검색은 `dropZero()` 로 이미 구제되므로 **표시명만의 문제**라 우선순위가 낮다.
발견하는 대로 `zero_soda_label.json` 에 추가한다.

## 신고서에 감미료가 없어도 라벨에 있을 수 있다 - 2026-08-20

`제로슈거 하이진저`는 C002 신고 원재료에 감미료가 **한 건도 없어** 무감미료(최상위)로
표시됐으나, 라벨에는 **알룰로스·수크랄로스·아세설팜칼륨**이 명시돼 있었다.
275mL 33kcal 로 제로칼로리 기준(100mL당 4kcal)도 넘는다.

그래서 표시원재료 적용 조건을 넓혔다. `canonicalize()` 는 C002 판정이
**`?`(혼합제제로 가려짐) 또는 `무감미료`(신고서에 감미료 없음)** 일 때만 라벨로 덮어쓴다.
신고서의 '없음'보다 라벨의 '있음'이 구체적인 증거이기 때문이다.
**C002 가 이미 감미료를 짚은 제품은 건드리지 않는다** - 이 경계는 그대로다.

반대 방향도 쓸모가 있다. `하이트제로 0.00` 은 라벨에도 감미료가 없어(폴리덱스트로스는
식이섬유다) **무감미료가 확정**됐고 경고 표시가 사라졌다. 회귀 테스트는
`LabelIngredientTests` 의 `test_label_overrides_no_sweetener_filing` 과
`test_label_can_confirm_no_sweetener` 다.

### 번호가 안 맞을 때의 예외 하나

`환타 제로 오렌지향`(튤립인터내셔널, `20190575042219`)은 라벨 제품명이 등록명과 정확히
일치하지만, 캔에 인쇄된 번호는 자매 레코드 `환타 제로 오렌지` 쪽 공장(P7·P14)이었다.
두 레코드의 C002 원재료 패턴이 동일해 같은 배합으로 판단했고, **번호 단위 확인이 아니라
제품명 일치에 근거한 판단임을 `대조` 필드에 적어 두었다.** 이런 예외는 반드시 명시할 것.
