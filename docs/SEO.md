# SEO 운영 메모

`fire-your-seo-agency` 스킬 절차로 2026-08-30 에 진행한 작업과 남은 일.

## 이 사이트의 구조적 한계

단일 페이지 앱이다. 제품 616개가 `<script type="application/json">` 안에 있고
표는 JS 가 그린다. 그래서 **크롤러가 읽는 가시 텍스트가 1,730자뿐**이었다
(HTML 485KB 중 91%가 JSON). 제품별 URL 도 없다.

리액트로 다시 쓰거나 제품별 페이지 616장을 만드는 대신, **빌드 때 무JS 정적
페이지를 같이 뽑는 방식**으로 풀었다. 앱은 그대로 두고 크롤러·AI 에게는 정적
표를 준다.

## 산출물 (`write_seo_files`)

|경로|내용|
|---|---|
|`products.html`|616개 전량 정적 표. 가시 텍스트 46,210자|
|`allulose.html`|알룰로스 쓰는 제품|
|`no-aspartame.html`|아스파탐 없는 제품|
|`no-erythritol.html`|에리스리톨 없는 제품|
|`no-caffeine.html`|카페인 없는 제품|
|`fake-zero.html`|제로 표기 + 당류 있음|
|`hidden-zero.html`|이름에 제로 없는데 0kcal|
|`llms.txt`|생성엔진용 안내서. 1차 소스임을 명시|
|`llms-full.txt`|616개 전량 마크다운 표|
|`og-card.png`|1200x630. **숫자를 넣지 않아** 갱신돼도 낡지 않는다|

의도 랜딩은 `seo_landing_specs()` 에 정의한다. 새 질문을 추가하려면 여기에
`(slug, title, desc, h1, 직답, 대상 레코드, 읽는 법)` 한 줄을 넣으면
페이지·사이트맵·llms.txt 링크가 모두 따라온다.

## 지켜야 하는 규칙

- **가시 FAQ 와 FAQPage LD 는 `_FAQ` 상수 하나에서 만든다.** 둘을 따로 쓰면
  글자가 어긋나고, 가시 텍스트와 다른 구조화 데이터는 스팸 판정 위험이다
- **ItemList LD 의 항목은 화면 표에 실제로 있는 제품만** 넣는다 (상위 100개 제한)
- **직답 문단은 첫 화면에.** 답변엔진은 페이지를 요약하지 않고 답이 되는 문장을
  추출한다. "결론부터: … <b>N개</b>입니다" 형식을 유지할 것
- **열량·당류에는 항상 기준을 붙인다** (100mL당). 기준 없는 숫자는 답변엔진이
  신뢰 판정에서 감점하고, 라벨(한 병 기준)과 달라 보여 사용자도 혼동한다
- robots.txt 에서 AI 크롤러를 막지 말 것. 공개 정부 데이터이고 산출 코드도 MIT 다

## 사용자 계정이 필요한 남은 작업

1. **Bing Webmaster Tools 등록** — GSC 에서 원클릭 임포트. ChatGPT 검색이 Bing
   색인에 의존하므로 AEO·GEO 의 절반이다
2. **Search Console 사이트맵 재제출** — URL 이 1개에서 8개로 늘었다
3. **네이버 서치어드바이저** 사이트맵 제출 + 웹페이지 수집 요청
4. **IndexNow 키 발급** 후 `INDEXNOW_KEY` 환경변수 + `docs/<key>.txt` 배치.
   그러면 `--mode sync` 가 갱신 때마다 Bing·네이버에 자동 통보한다
